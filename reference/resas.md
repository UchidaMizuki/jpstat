# Access 'RESAS' data (defunct)

**\[defunct\]**

## Usage

``` r
resas(...)
```

## Arguments

- ...:

  Ignored.

## Value

This function always errors.

## Details

The 'RESAS' API (<https://opendata.resas-portal.go.jp/>) was
discontinued on 2025-03-24, and accounts as well as API keys were
deleted. Therefore `resas()` no longer works and has been made defunct.

As an alternative for prefectural and municipal data, consider the MLIT
Data Platform (DPF) GraphQL API (<https://www.mlit-data.jp/>).
